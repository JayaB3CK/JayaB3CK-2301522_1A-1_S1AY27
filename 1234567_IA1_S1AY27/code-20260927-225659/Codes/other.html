Web Pages and Purpose

Website Theme

The design is minimal and calm, built around a navy and warm orange palette that reflects my creative side while staying readable for long-form content. Typography uses the Lora serif family for a soft, editorial feel. The layout stays responsive, moving from a single column on mobile to a two-column grid on desktop.

Website Features

  • Sticky navigation bar for easy access to all pages.
  • Clickable ID image that opens the local mail client.
  • Bookmark links on the Personal Development page for jumping between sections.
  • Responsive layout across mobile (600 px), tablet, and desktop (950 px+).
  • Single external stylesheet driving a consistent colour scheme and typography.
